Block รวมสองอย่างไว้ในแอปเดียว: ข้อมูล Bitcoin บนหน้าจอหลักแบบดูปราดเดียวรู้ และแอปโซเชียล Nostr สำหรับคนที่คุยเรื่อง Bitcoin

<b>วิดเจ็ต Bitcoin</b>
<ul>
<li>วิดเจ็ตหน้าจอหลักสไตล์ blockclock: ราคา, sats ต่อดอลลาร์หรือบาท, ความสูงบล็อก, ค่าธรรมเนียม, hash rate, ความยาก, นับถอยหลัง halving, ความจุ Lightning, การถือ Bitcoin ของ Strategy (MSTR) และ Strive (ASST) และมูลค่า stack ของคุณ</li>
<li>วิดเจ็ตกราฟราคา (24H / 7D / 30D / 1Y), นับถอยหลัง halving และคำคม Bitcoin ปรับขนาดได้ทุกตัว</li>
<li>เลือกได้ทั้ง USD และ THB พร้อมแหล่งราคาที่ต้องการ</li>
</ul>

<b>โซเชียล Nostr</b>
<ul>
<li>ไทม์ไลน์แบบ X: โพสต์, ตอบกลับ, รีโพสต์, อ้างอิง, ไลก์, รีแอกชัน และ zap</li>
<li>ข้อความส่วนตัวและแชทกลุ่ม (NIP-17), ลิสต์, บุ๊กมาร์ก, ไลฟ์ และบทความ</li>
<li>อัลบั้มรูป, วิดีโอ, โพล, ตัวอย่างลิงก์ และการ์ดแสดงธุรกรรมและบล็อก Bitcoin แบบสด</li>
<li>แท็บกระเป๋า Lightning ผ่าน Nostr Wallet Connect (NWC): ดูยอดเงิน รับด้วย QR code ส่งโดยวางหรือสแกนใบแจ้งหนี้ และ zap ในแตะเดียว</li>
<li>จัดการ relay ได้เอง: outbox model, ตรวจและแนะนำ relay</li>
<li>Proof of work (NIP-13) สำหรับโพสต์ และธีมต่างๆ รวมถึง Ember จาก Zeus</li>
</ul>

<b>ความเป็นส่วนตัวมาก่อน</b>
ไม่ต้องสมัครบัญชีกับเรา ไม่มีโฆษณา ไม่มีการเก็บสถิติหรือติดตามผู้ใช้ ข้อมูลตลาดมาจากแหล่งสาธารณะ ข้อมูลโซเชียลมาจาก relay ที่คุณเลือก กุญแจของคุณอยู่ในเครื่อง (เข้ารหัสด้วย Android Keystore) หรือในแอป signer

Block แสดงข้อมูลเท่านั้น ไม่ใช่ตลาดซื้อขาย และไม่ใช่คำแนะนำทางการเงิน
